# Instrucciones del proyecto DDNA

## Protección del sitio y del contenido existente

Nunca realizar migraciones masivas, eliminación o reemplazo de contenidos del sitio DDNA existente sin una instrucción explícita.

- El sitio productivo actual es una referencia y no debe modificarse desde este proyecto.
- No interpretar auditorías, modelos de contenido o estructuras preparatorias como autorización para importar contenido.
- No crear redirecciones definitivas ni cambiar URLs productivas sin aprobación explícita.
- Consultar `docs/project-scope.md` antes de ejecutar tareas relacionadas con migración, producción o contenido histórico.
